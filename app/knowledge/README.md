# 知识库 (Knowledge)

4.0 自带知识库。明文 MD 文件存放在本目录，按分类组织。

## 目录结构

```
app/knowledge/
├── README.md                ← 本文件
├── builtin/                 ← 内置知识（预置，用户可读/可复制/可改）
│   ├── 文风语料/            ← A1 检索时优先取（题材感知）
│   ├── 桥段/                ← A1 检索时优先取（题材感知）
│   ├── 人物人设/            ← 配套（A1 不取，避免污染）
│   ├── 场景描写/            ← 配套
│   └── 框架模板/            ← 配套
├── local/                   ← 用户本地知识（C1 导入 + 手动添加 + 批量灌入）
│   ├── 文风语料/
│   ├── 桥段/
│   ├── 人物人设/
│   ├── 场景描写/
│   └── 框架模板/
└── index/                   ← 索引缓存（BM25 + 向量，运行时生成）
```

## 使用方式

- **内置知识 (builtin)**：4.0 自带的题材素材，覆盖仙侠/古言/都市/悬疑/科幻 5 大题材
- **本地知识 (local)**：用户通过"知识库"Tab 手动添加/上传的素材；也可通过 `python tools/copy_local_kb.py` 从外部目录批量灌入（部署/迁移场景）
- **索引 (index)**：F1 BM25 + F2 向量 DB 缓存，运行时自动生成，无需手动维护

## 检索策略 (A1 拍板)

- **每章检索**：每章写之前，按章节任务动态取（F1 + F2 混合）
- **只取文风 + 桥段**：A1.7 拍板，其他 3 类不取，避免污染
- **每类 1-2 段**：A1.8 拍板，总 ~200 字
- **0 污染**：检索内容只进 system 段，不污染 user 段上下文

## 维护规则

- 改 `builtin/` 不会破坏软件（明文，下个版本可重置）
- 改 `local/` 是用户自己内容，永久保留
- 删 `index/` 不会丢数据，下次启动自动重建
- 批量导入外部知识库：把 MD 放到对应子目录（文风语料/桥段/人物人设/场景描写/框架模板），或用 `python tools/copy_local_kb.py --dry-run` 看计划后去掉 `--dry-run` 实际复制
  - 复制完**必须重启主程序**才能触发索引重建（`index/` 下的 bm25.pkl / vectors.npy 会重新生成）

## 用户使用

用户可以在"知识库"Tab 查看所有 MD 文件 / 上传新 MD / 删除（详见 C1 导入）。
