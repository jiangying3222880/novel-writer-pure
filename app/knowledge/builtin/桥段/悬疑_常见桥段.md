# 悬疑常见桥段

## 桥段 1：密室杀人

**核心套路**：看似不可能的密室 / 不可能的凶器 / 不可能的时间。

**节奏控制**：
- 1/4：尸体被发现（细节一定要具体——位置、姿态、伤口）
- 1/2：侦探 / 警察介入，列出 3-5 个疑点
- 3/4：嫌疑人逐一被排除 / 自证清白
- 高潮：真相揭晓（机关 / 盲点 / 时间错位）

**反 AI 味要点**：
- 真相不能"靠凶手自白"（要用物证 / 时间线 / 第三方证据）
- 侦探不能"全知全能"（要犯 1-2 个错 / 漏看 1-2 个细节）
- 凶手动机不能"为爱复仇"（太套路，要有个性化动机）

## 桥段 2：童年阴影

**核心套路**：主角/配角童年有过创伤，多年后重新被触发。

**节奏控制**：
- 1/4：创伤不直接点明（用"异常反应"暗示——怕某种声音、某种食物、某种动物）
- 1/2：相似场景再现（撞见 / 重访旧地 / 遇见当事人）
- 3/4：触发崩溃 / 强迫症发作
- 收尾：自我救赎 / 接受 / 复仇

**反 AI 味要点**：
- 不能"全靠哭诉"（童年创伤用 1-2 笔细节暗示，不展开）
- 不能"立刻好起来"（救赎要 3-5 章的过渡）
- 创伤不能"全员一致"（每个人应对方式不同：有人逃避 / 有人控制 / 有人模仿）

## 桥段 3：叙述性诡计

**核心套路**：叙述者故意隐瞒 / 误导读者。

**节奏控制**：
- 全程：叙述者"可疑"（1-2 个细节不对劲，但读者会忽略）
- 1/2：第二个视角出现（开始怀疑第一个叙述者）
- 3/4：第一个叙述者"自爆"或被识破
- 收尾：真相可能是双胞胎 / 双重人格 / 故意隐瞒

**反 AI 味要点**：
- 叙述性诡计要"公平"（读者回看能发现伏笔）
- 不能"故弄玄虚"（诡计必须有动机 / 必要性）
- 真相揭晓后要让读者"啊原来如此"（不是"这什么鬼"）
