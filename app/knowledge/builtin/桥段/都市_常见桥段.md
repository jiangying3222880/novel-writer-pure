# 都市常见桥段

## 桥段 1：职场反杀

**核心套路**：主角被同事/上司穿小鞋 → 默默准备 → 一鸣惊人反杀。

**节奏控制**：
- 1/4 处：主角被穿小鞋的具体场景（不能让小鞋太"明显"，要让读者看穿反派意图）
- 1/2 处：主角暗中准备（学技能 / 拉拢关键人 / 留证据）
- 3/4 处：反派得意忘形，自爆弱点
- 高潮：主角一出手，直接踩死（不能太轻）
- 收尾：反派被边缘化 / 主动离职

**反 AI 味要点**：
- 主角不能"睚眦必报"（留 1-2 个"以德报怨"瞬间让反派难堪）
- 反派不能"脸谱化"（给反派加 1-2 个家庭/性格软化点）
- 反杀手段要"专业"（不能靠运气，要靠实力/智谋）

## 桥段 2：霸总/灰姑娘（老套但读者爱）

**核心套路**：普通女孩/男孩误入豪门 / 商业帝国 / 名流圈。

**节奏控制**：
- 1/4：身份错位（女主闯入不该去的地方 / 偶遇霸总）
- 1/2：双向误会（霸总误以为女主有企图 / 女主误以为霸总是登徒子）
- 3/4：真相 + 反派搅局
- 收尾：身份揭晓，HE

**反 AI 味要点**：
- 女主不能"傻白甜"（必须有 1 项专业能力 / 独立人格）
- 霸总不能"面瘫全程"（至少 2-3 处露出"非霸总"的一面）
- 不能"全员有钱人"（女主的家人朋友要真实）

## 桥段 3：老同学聚会的暗流

**核心套路**：多年未见的老同学聚会，每个人都变了 / 都没变。

**节奏控制**：
- 1/4：聚会前的犹豫（该不该去 / 要不要带对象）
- 1/2：聚会的表面热闹（敬酒 / 寒暄 / 摆谱）
- 3/4：厕所 / 阳台 / 散场后的私下对话（真实心思）
- 收尾：有人破产 / 有人上位 / 有人失踪

**反 AI 味要点**：
- 不能"全员势利"（老同学里至少 1-2 个还保持真心）
- 不能"主角全程被嘲讽"（主角至少 1 处"高光"）
- 收尾要"留白"（不点破每个人的现状）
