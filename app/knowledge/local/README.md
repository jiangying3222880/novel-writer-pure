# 用户本地知识库

把你积累的素材（文风笔记 / 桥段摘录 / 人物设定 / 场景草稿 / 框架模板）按分类放到对应子目录。

## 怎么用

1. **手动添加**：把 .md 或 .txt 文件直接拖到对应子目录里
2. **软件导入**：在"知识库"Tab → "本地知识" → 上传文件（走 C1 导入流程）
3. **搜索**：在"知识库"Tab 搜索框输入关键词

## 格式建议

每个文件建议带 frontmatter（可选）：

```markdown
---
genre: 仙侠
tags: [师徒, 虐心]
---

# 正文从这里开始
...
```

## 注意事项

- 一次建议放 1 个完整素材（不要把多个素材混在一个文件里）
- 改文件名不会影响索引（下次启动会重建）
- 删了文件，对应索引也会自动失效
