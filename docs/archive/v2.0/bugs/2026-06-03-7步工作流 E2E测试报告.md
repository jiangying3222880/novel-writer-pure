## 八、测试中发现的问题（不是 bug，是认知偏差）

### 问题 1: Checkpoint 目录位置

**之前以为**：`d:/novel-writer-pure/story/...`
**实际**：`C:\Users\jy322\.novel-writer-pure\story\...`（用户家目录）

**根因**：[app/db/connection.py:13](file:///d:/novel-writer-pure/app/db/connection.py#L13) `BASE_DIR = Path.home() / ".novel-writer-pure"` 

**影响**：之前测试结果可能因路径错误以为 checkpoint 失败。实际所有 checkpoint 都正确保存到用户家目录。

### 问题 2: MockAIEngine 需要 extract_json

**根因**：[PlannerAgent._parse_planner_result](file:///d:/novel-writer-pure/app/workflow/agents/planner.py#L258) 直接调 `self.ai_engine.extract_json(content)`

**修复**：Mock 引擎需要实现 `extract_json()` 方法（解析 ```json``` 块或 `{...}` 块）

**实际**：[2026-05-20 修复](file:///d:/novel-writer-pure/docs/BUG修复记录/2026-05-20.md) 专门为 MiniMaxAIModel 添加了 `extract_json` 方法。

### 问题 3: AUDITOR 输出是规则引擎报告而非 mock 响应

**根因**：AUDITOR 步骤**先做确定性检查**（规则引擎）再调 AI。我的 mock 没有拦截这个规则引擎，所以 31 字符是规则引擎"快速失败"的输出。

**结论**：这是**正常行为**，说明 AUDITOR 步骤的规则引擎**在工作**。
