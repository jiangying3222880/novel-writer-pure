### Q-9: JSON 解析静默失败（**实际有 14 处**）

**问题扩大**：TODO 文档中写 3 处，实际有 **14 处**（[app/db/project_db.py](file:///d:/novel-writer-pure/app/db/project_db.py) L863, 894, 955, 1041, 1083, 1138, 1285, 1384, 1672, 1698, 1781, 1786, 1850, 1855）。

**修复方案**：抽统一解析函数到 [app/db/project_db.py](file:///d:/novel-writer-pure/app/db/project_db.py) 顶部：

```python
def _safe_json_loads(text: str, default=None, field_name: str = "field") -> Any:
    """安全解析 JSON 字段，失败时记录 warning 并返回 default"""
    if not text:
        return default if default is not None else {}
    if isinstance(text, (dict, list)):
        return text
    try:
        return json.loads(text)
    except (json.JSONDecodeError, TypeError) as e:
        logger.warning(f"[DB] 字段 {field_name} JSON 解析失败: {e}")
        return default if default is not None else {}
```

**批量替换**：14 处 `try: json.loads(...) except (json.JSONDecodeError, TypeError): pass` 全部改为调用 `_safe_json_loads(text, field_name="...")`。
