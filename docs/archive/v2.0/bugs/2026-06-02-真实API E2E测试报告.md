## 四、新发现的问题

### ❌ P-NEW-1: 多文件导入角色批次未输出（影响场景 3, 4）

**问题描述**：
- 多文件-梦里叫主人（应有 11 个角色）：导入 0 个
- AI多文件-普通人穿越（应有 20+ 角色）：导入 0 个
- 单文件-星尘方舟：导入 8 个角色（正常）

**根本原因**：
- 多文件场景总字符量 50K-80K 字符
- AI 引擎 Token 限制（模型上限 16384 tokens）
- `_ai_parse_sync` 自动截断到 50000 字符（`max_chars = 50000`）
- 即使截断后，**剩余部分仍可能超过模型 token 限制**
- 截断导致角色批次 AI 没看到角色数据，返回空数组

**日志证据**：
```
[Import] 内容截断(Sync): 77605 -> 50000 字符
[AI] Token截断警告: prompt=73741 tokens, 模型上限=16384, 安全边...
```

**修复方向**（架构级）：
1. 分批（chunked）处理大文件：把大文件拆成多个小批次，**每个批次聚焦一种类型**（character/world/chapter）
2. 当前 `max_chars = 50000` 与模型 16384 tokens 不匹配，**应该先按 token 估算再截断**
3. 或在导入前用文本分析预判文档结构（"角色设定.md" 应该作为 character 批次处理，而不是 world）

**P-NEW-1 严重度**：🟡 P1（多文件功能不可用，但单文件功能正常）

### ❌ P-NEW-2: AI 响应不包含完整字段（影响所有场景）

**问题描述**：
- 真实 API 返回的角色数据**没有** `gender`、`age`、`abilities`、`author_requirements` 等字段
- AI 模型只输出了 `name`、`personality`、`background`、`role_type`
- 即使 P1-3 修复在代码层有效，AI 没传数据，DB 中字段就为空

**根因分析**：
- 当前 prompt 鼓励 AI 输出 11 个字段，但**没有强制要求**所有字段
- AI 在 token 紧张时（多文件场景）会优先输出最重要的字段
- AI 在 token 富余时（单文件场景）也**不会**主动输出 `age`/`gender`，因为 prompt 中描述模糊

**修复方向**：
1. 在 prompt 中明确"**所有 11 个字段都必须输出，无值时输出空字符串**"
2. 强化示例（JSON 示例中展示完整 11 字段）

**P-NEW-2 严重度**：🟡 P2（不影响导入，但影响数据完整性）

### ⚠️ P-NEW-3: 角色被错误归类为 world_settings

**问题描述**：
- 多文件-梦里叫主人有 109 条 world_settings
- 其中 80+ 条实际上是角色的表格属性（"年龄=30岁"、"体香=雪松与白茶"等）
- AI 误解了这些是"世界设定"而非"角色属性"

**修复方向**：
- 在 prompt 中再次强调"角色表格属性**应作为 character.author_requirements 持久化**"
- 但**实际** AI 在多文件+大批量时会优先用 world_settings（因为 all 模式要求 world 批次独立输出）

**P-NEW-3 严重度**：🟢 P3（数据冗余但无错误）
