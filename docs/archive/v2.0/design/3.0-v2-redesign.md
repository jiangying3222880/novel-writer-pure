## 3.0 v2 核心设计（保留 3.0 范式）

### 原则 1：3 阶段范式**严格化**

**基础三阶段**（默认）：
- WRITE → SELF_CRITIQUE → PERSIST
- 不允许 DONE 当独立 phase（DONE 是 PERSIST 完成后的状态）
- V3_DEFAULT_STEPS 必须有且仅有 3 个
- V3_USER_CONFIRM_STEPS（4 槽位）和 V3_MULTI_VERSION_STEPS（5 槽位）只作为**插件/场景**扩展，不动核心

**配置层单一来源**：
```python
# 单一 truth source
V3_AGENT_DEFINITIONS = {
    0: {"name": "WRITE", ...},
    1: {"name": "SELF_CRITIQUE", ...},
    2: {"name": "PERSIST", ...},
}

# 扩展只是别名
V3_USER_CONFIRM_AGENT_DEFINITIONS = {0: WRITE, 1: USER_CONFIRM, 2: SELF_CRITIQUE, 3: PERSIST}
V3_MULTI_VERSION_AGENT_DEFINITIONS = {0: WRITE, 1: SELECT_VERSION, 2: SELF_CRITIQUE, 3: PERSIST, 4: PERSIST}
```
