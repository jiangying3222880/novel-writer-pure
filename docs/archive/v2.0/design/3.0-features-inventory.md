## 1. 核心业务功能（3.0 范式 + 4 大引导元素 + 6 验证器）

### 1.1 3 阶段工作流（基础）
- **WRITE**（1 次 LLM）→ 章节正文初稿
  - 接收 SceneContext（4 大引导元素 + RAG 预取）
  - Token：~8-10K
- **SELF_CRITIQUE**（1 次 LLM）→ 自评分 + 4 问自评
  - Token：~4-5K
- **PERSIST**（0 token）→ 6 验证器 + 落库
  - 风格指纹增量学习
  - 声音档案增量更新
  - 跨章一致性检查

### 1.2 3.1 增强工作流（3-5 阶段范式）
- **模式 A**（11 章后）：Write → Self-Critique → Persist（3 槽位）
- **模式 B**（前 10 章）：Write → USER_CONFIRM → Self-Critique → Persist（4 槽位）
- **模式 C**（多版本）：Write → SELECT_VERSION → USER_CONFIRM → Self-Critique → Persist（5 槽位）

### 1.3 4 大引导元素（SceneContext 一次注入 Writer）
| 元素 | 文件 | 职责 |
|------|------|------|
| **潜文本卡** | `app/workflow/subtext_card.py` | 表面事件 / 真实意图 / 谎 / 真 / 物理锚点，引导写"潜文本+身体反应+留白" |
| **角色声音档案** | `app/workflow/voice_profile.py` | 句法+词汇+决策+关系指纹，告别"性格：怂" |
| **作者风格指纹** | `app/workflow/style_fingerprint.py` | pace / density / lyricism 三轴 + 漂移检测 + 自动学习器 |
| **反规则** | `app/workflow/anti_rule.py` | "在 Y 范围内允许打破 X"，给 AI 灵性空间 |

### 1.4 6 个本地验证器（0 token）
| 验证器 | 文件 | 解决问题 |
|--------|------|----------|
| POV 验证器 | `pov_validator.py` | 人称占比，视角乱 |
| 空间验证器 | `spatial_validator.py` | 方向/位置一致性 |
| 声音验证器 | `voice_validator.py` | 角色风格漂移 |
| 设定覆盖率 | `setting_recall.py` | 核心设定+活跃伏笔不丢失（10 章后遗忘）|
| 重复检测 | `repetition_detector.py` | 句首词频/整句重复/三连短句 |
| 物品/承诺校验 | `item_validator.py` | 物品一致性+承诺追踪 |

**统一接口**：`validate_xxx(text, **context) -> ValidationResult`（validator_name / passed / flags / details）

### 1.5 跨章一致性检查器
- `app/workflow/consistency_checker.py`：跨章设定/物品/对话/时序/情绪一致性

### 1.6 世界状态观察器
- `app/workflow/world_state_observer.py`：追踪跨章世界状态（数值/事件/状态）

## 9. 业务功能关键路径

### 9.1 主流程：写 1 章
1. 用户在章节生成 Tab 选章节号 + 流程配置
2. WRITE：拼 SceneContext（4 大引导元素 + RAG 预取）→ 调 LLM → 输出 draft
3. （可选）USER_CONFIRM：用户确认 SceneContext
4. SELF_CRITIQUE：调 LLM 自评 → 输出 4 问报告
5. PERSIST：6 验证器 + 跨章一致性检查 + 落库 + 风格指纹学习 + 声音档案更新

### 9.2 辅助流程
- **记忆蒸馏**：每章完成后自动 → STM → MTM → LTM
- **RAG 检索**：写作时被动调用 → top-k 召回
- **大纲生成**：ai_outline_gen 插件触发 → 生成 worldview/character/chapter_brief
- **剧情推演**：plot_deduction 插件触发 → 多轮 AI 推演

### 9.3 自评阻断
- technical_score < 60：阻断（需重写）
- taste_score < 60：非阻断黄色提示（仅参考）
