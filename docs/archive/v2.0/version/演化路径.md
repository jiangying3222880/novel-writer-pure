## 阶段 1：v0.x 写作技能时代（pre-2026-05-17）

> **本阶段为 jy 命名的早期独立项目，仅沉淀写作技能材料，不是 novel-writer-pure 的代码。已不再维护，仅作历史参考。**

### 1.1 载体与时间
- **载体**：`_temp/novel-writer-jy-v5.4/novel-writer-jy/`（独立目录，不在 novel-writer-pure 仓库内）
- **版本号**：v5.4（SKILL.md frontmatter）/ v5.0.0（database 子模块）
- **时间**：pre-2026-05-17

### 1.2 定位
**写作技能阶段**——jy 早期独立沉淀的"小说写作方法论 + 知识库 + 提示词库"。这是一个 **"AI 辅助写作的方法论手册"**，不是 novel-writer-pure 的代码前身。
- 形态：markdown 文档 + SQLite 数据库（写作知识库）
- 用途：作为"prompt 教科书"嵌入到 AI 助手的工作流中
- 包含：7 步工作流规范、6 大题材教程、14 个拆文案例、200+ 提示词模板

### 1.3 核心内容
#### 1.3.1 方法论文档
- **`SKILL.md`**（version: 5.4）— 7 步工作流规范（Planner→Writer→DeepReader→DeepEditor→Auditor→Reviser→Settler）
  - 9 个 rules 文件（shared/planner/writer/deepreader/deepeditor/auditor/reviser/settler）
  - 2 个 references（20 维度审核表、审核报告模板）
  - 6 个辅助 Python 脚本（破折号检测、字数统计、视角检测、Hook 追踪、checkpoint 验证等）
- **`database/00-index.md`** — 36 张表概览
  - 业务库 21 张表（meta/volumes/characters/chapter_briefs/hooks/prohibitions/workflow/...）
  - 共享知识库 15 张表（writing_techniques/cool_point_patterns/character_archetypes/...）
- **`database/queries.md`** / **`database/schemas.md`** — SQL 查询示例 + 表结构定义

#### 1.3.2 知识库目录（60+ 文件）
| 子目录 | 文件数 | 内容示例 |
|--------|--------|---------|
| `knowledge/case_studies/` | 14 | 与凤行拆文、媚鱼拆文、凡人修仙传参考、50个小说经典情节、七步搞定一个情节设定、750个现代文剧情点、期待感人设日常 |
| `knowledge/characters/` | 19 | 教程19：外貌描写的终极攻略、教程20：对话描写、教程21：四种方法写好人物心理、女子描写篇、历史人物轶事解说 |
| `knowledge/concepts/` | 200+ | `deepseek_*` 指令库（玄幻/仙侠/古言/同人/悬疑/穿越/系统文/读心术/追妻火葬场等 45+ 类）、`doubao_*` 模板（仿写/公文/职场/论文/诗词等 30+ 类）、`kuang_*` 大神教程（写作/大纲/素材/系统/教程 60+ 篇） |

#### 1.3.3 关键决策（v0.x 内部版本演化）
- **v3.7 → v4.0**：Markdown 文件存储 → SQLite 结构化存储（database 21张业务表 + 15张知识表），支持复杂查询和防偷懒验证
- **v4.0 → v5.0**：增加共享知识库（`writing_knowledge_seed.db`），所有小说项目共享
- **v5.0 → v5.4**：增加 20 维度审核体系 + 29 种 AI 痕迹修复 + Hook 追踪债务机制 + AI 去味（番茄风第一人称）

### 1.4 演化驱动力
- jy 早期独立沉淀，**方法论先行**（先把"写小说到底需要什么步骤"想清楚）
- 大量拆文与教程积累，为后续 v1.0 提供 prompt 原材料
- **7 步工作流**是 jy 阶段的精华产物（后续 v1.0 直接工程化）

### 1.5 当前状态
- **已不再维护，仅作历史参考**
- 顶层目录仍在 `_temp/novel-writer-jy-v5.4/` 保留，但不再同步更新
- 核心方法论（7 步工作流）已被 v1.0/v2.0 工程化
- 拆文案例与教程可作为"灵性参考"，但 3.0 不再依赖其作为 prompt 来源
- 与 novel-writer-pure 的关系：**灵感来源 + 方法论起点**，但代码层面无任何依赖

- **7 步工作流**：`Planner → Writer → Auditor(增强版) ↔ Reviser → Polisher → Verify → Settler`

- **三视角 Auditor**：20 维度 + 证据制度 + P0/P1/P2 分级 + 防假审核
- **混合 RAG**：向量 + BM25 + RRF 融合
- **分层记忆**：LTM（长期记忆）+ STM（短期记忆）+ 蒸馏（每 8 章）

## 阶段 4：v3.0 引导性写作范式（2026-06-05~）

> **从"约束 + 禁止 + 审计保护 Agent"转向"用潜文本 + 声音 + 风格引导 Agent 一次写好"**。1 次强写 + 1 次轻量自评 + 0 token 本地验证。

### 4.1 起点
- **设计文档**：`novel-writer-3.0-architecture.md`（2026-06-05）
- **实施计划**：`novel-writer-3.0-implementation-plan.md`（5 个里程碑 M1-M5）
- **M1-M5 五个里程碑**：
  - **M1**：潜文本卡三模式入口（手填 / AI 生成 / Writer 自推）
  - **M2**：RAG 预取 + 6 个本地验证器
  - **M3**：3 阶段范式（Write → Self-Critique → Persist）
  - **M4**：完整章节 E2E（含所有引导元素）
  - **M5**：50 章连贯生成 + 打包验证

### 4.2 核心范式转变
| 维度 | 2.0（防御性） | 3.0（引导性） |
|------|--------------|--------------|
| 工作流 | 7 步串行（Planner→Writer→Auditor→Reviser→Polisher→Verify→Settler） | **3 阶段**（Write → Self-Critique → Persist） |
| Token/章 | ~50K | **~12-15K**（**-70%**） |
| AI 调用次数 | 5-7 次/章 | 2 次/章（Write + Self-Critique） |
| 约束方式 | 禁止项 + 20 维度扣分 | 潜文本卡 + 声音档案 + 风格指纹 + 反规则 |
| 验证方式 | LLM 审计 + 修补 | **0 token 本地验证器** + 6 个确定性检查 |
| 失败处理 | Reviser 循环修补 | Self-Critique 自评 + 标记由作者决定 |
| 角色一致性 | 性格标签（如"性格：怂"） | **句法 + 词汇 + 决策模式指纹** |
| 风格一致性 | 20 维度评分 | **pace / density / lyricism 三轴** + 漂移检测 |
| 视角合规 | LLM 自检 | **POV 验证器**（0 token 正则） |
| 空间一致性 | LLM 自检 | **空间验证器**（0 token） |
| 重复检测 | 无 | **重复句式检测器**（0 token） |
| 物品一致性 | 故事线追踪 | **物品/承诺校验器**（0 token） |
| 跨章一致性 | LTM/STM | **ConsistencyChecker**（5 种，0 token） |

### 4.3 核心创新
- **潜文本卡（SceneSubtextCard）**（`app/workflow/subtext_card.py`）
  - 5 个核心字段：表面事件 / 真实意图 / 谎 / 真 / 物理锚点
  - 引导 Writer 写出"潜文本 + 身体反应 + 留白"
  - 三模式入口：手填 / AI 生成 / Writer 自推
- **角色声音档案（CharacterVoiceProfile）**（`app/workflow/voice_profile.py`）
  - 句法 + 词汇 + 决策 + 关系指纹
  - Few-shot 自动从历史对话中挑样本
  - 告别"性格：怂"关键词式设定
- **作者风格指纹（AuthorStyleFingerprint）**（`app/workflow/style_fingerprint.py`）
  - pace / density / lyricism 三轴
  - 冷启动默认 0.5/0.5/0.5，写完后增量学习
  - 漂移检测：偏离初始值 > 0.3 → 提示用户
- **反规则系统（Anti-rule Allowance）**（`app/workflow/anti_rule.py`）
  - 不是"禁止 X"，而是"在 Y 范围内允许打破 X"
  - 与风格指纹配套，告诉模型在安全边界内可以"犯错"
- **6 个本地验证器**（`app/workflow/validators/`）
  - POV / 空间 / 声音 / 设定 / 重复 / 物品（0 token 本地操作）
- **一致性检查器**（`app/workflow/consistency_checker.py`）
  - 跨章设定 / 物品 / 对话 / 时序 / 情绪一致性
  - FLAG 模式不阻断流程，由作者决定是否采纳

### 4.6 演化驱动力

## 未来规划

> **3.0 之后暂无 v4.0 计划。**

novel-writer-pure 3.0 是单用户自用测试项目的收尾版本。3.0 范式（引导性写作 + 0 token 本地验证 + 3 阶段流程）已经达到了"用 AI 写长篇网文"的质量与成本平衡点。

如果未来需要继续迭代，更可能的方向是：

- **继续优化 3.0 范式内的细节**（验证器扩展、风格指纹学习、声音档案冷启动）
- **小颗粒度补丁**（不破坏 3.0 范式）
