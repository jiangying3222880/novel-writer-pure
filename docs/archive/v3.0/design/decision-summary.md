1. **顺序**：底层类（阶段 1-3）→ UI 类（阶段 4-6）→ 插件类（阶段 7），不能颠倒
2. **每阶段必跑 smoke**：m0-m6 7 套 smoke，**全过**才进下阶段
3. **UI 重写前**：必先生成 HTML 效果图给用户过目，**用户确认后**才动手

5. **退路**：每个阶段保留切换旧 3.0 的开关，4.0 跑不起来可降级
