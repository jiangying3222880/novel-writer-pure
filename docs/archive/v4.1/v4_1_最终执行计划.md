## 四、Phase 2：核心差异化功能（P0 本周，5天）

### 4.1 冲突日志（conflict_log）

**目标**：记录因果冲突，支持人工干预

**文件**：`app/services/conflict_log.py`（新增）

| 函数 | 说明 |
|------|------|
| `log_conflict(unit_id, conflict_type, description)` | 记录冲突 |
| `get_conflicts(unit_id)` | 获取单元冲突列表 |
| `resolve_conflict(conflict_id, resolution)` | 标记冲突已解决 |

### 4.2 增量补丁（patch_preview）

**目标**：展示AI生成的增量变更，支持人工预览

**文件**：`app/services/patch_preview.py`（新增）

| 函数 | 说明 |
|------|------|
| `generate_patch(old_content, new_content)` | 生成差异补丁 |
| `apply_patch(content, patch)` | 应用补丁 |
| `preview_patch(patch)` | 格式化补丁预览 |

### 4.3 反向编译（reverse_compile）

**目标**：将文本反向解析为结构化大纲，支持编辑后重新生成

**文件**：`app/services/reverse_compile.py`（新增）

| 函数 | 说明 |
|------|------|
| `parse_outline(text)` | 解析文本为大纲结构 |
| `parse_characters(text)` | 解析文本中的角色信息 |
| `parse_events(text)` | 解析文本中的事件信息 |
