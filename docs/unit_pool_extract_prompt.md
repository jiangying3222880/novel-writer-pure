# 单元池素材提取 — 执行指令

## 你的任务

从网络收集真实故事素材（新闻、真实经历、论坛故事、短故事），提取为"故事单元"存入单元池。

**每个单元 = 一个乐高积木**：情绪完整、独立可读、不超过 1000 字。小说创作时从池里拼装使用。

---

## API 调用预算（严格遵守）

你只有 **1000 次** LLM 调用额度。必须精打细算：

| 阶段 | 调用次数 | 做什么 |
|------|----------|--------|
| 搜索 | ~100 次 | 搜索网页找素材 |
| 批量提取 | ~150 次 | 每次处理 3-5 篇文章，提取 15-25 个单元 |
| 质量抽查 | ~30 次 | 随机抽查 30 个单元的质量 |
| **合计** | **~280 次** | **预计产出 800-1500 个单元** |

**关键策略：** 每次提取调用处理 3-5 篇文章（批量），不要一篇一篇处理。

## 提取格式（必须遵守）

每次批量提取调用，输出一个 JSON 数组：

```json
[
  {
    "title": "标题（20字以内）",
    "content": "正文（≤1000字）",
    "genre": "都市",
    "scene_type": "setup",
    "emotion": "压抑",
    "rhythm_type": "rising",
    "tags": ["标签1", "标签2"]
  }
]
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|:----:|------|
| `title` | ✅ | 20 字以内，概括核心冲突 |
| `content` | ✅ | **≤ 1000 字**，有画面感，独立可读 |
| `genre` | ✅ | `通用` `仙侠` `都市` `悬疑` `言情` `科幻` `历史` `奇幻` |
| `scene_type` | ✅ | `setup` `rising` `climax` `falling` `transition` `revelation` `conflict` `resolution` |
| `emotion` | ✅ | `压抑` `爽` `虐` `燃` `甜` `愤怒` `悲伤` `恐惧` `温暖` `绝望` `希望` |
| `rhythm_type` | ✅ | `opening` `setup` `rising` `climax` `falling` `transition` `revelation` `conflict` `resolution` `ending` |
| `tags` | ❌ | 关键词标签 |

### scene_type 和 rhythm_type 的区别

- `scene_type`: 这个单元在故事中的**功能**（铺垫/高潮/过渡/揭秘...）
- `rhythm_type`: 这个单元的**节奏位置**（开篇/升温/高潮/下降...）

两者经常相同，但不完全一样。例如一个"揭秘"场景可能出现在"升温"阶段。

## 内容处理规则

### 新闻 → 改写为文学语言

新闻是干巴巴的，必须改成小说能用的样子：

```
新闻原文：
  "3月15日，某小区一老人摔倒，路人将其扶起送医。"

改写后：
  "小区的路灯还没全亮。张大爷只觉得脚下一软，膝盖磕在水泥地上。
  
  路过的外卖小哥停下电动车，犹豫了两秒——还是蹲下来，把老人扶了起来。
  
  老人的手冰凉，死死抓着小哥的胳膊，像抓着救命稻草。"
```

**规则：** 加五感（视/听/嗅/触/温度），加心理活动，不抄新闻词句。

### 论坛/贴吧故事 → 洗脏水留金子

**洗掉：** 水话（"第一次发帖好紧张"）、网络梗（"蚌埠住了"）、语气填充词

**保留：** 真实情绪、生活细节、对话节奏

### 短故事 → 按情绪转折拆分

一个情绪转折 = 一个单元。一段不超 1000 字。

---

## 合格标准（每次提取后自检）

```
□ 字数 ≤ 1000？
□ 有明确情绪？（读者会感觉到什么？）
□ 有画面感？（能看到场景？能听到声音？）
□ 独立可读？（不看前文也知道在讲什么）
□ genre 填了？
□ title 在 20 字以内？
```

---

## 输出方式

处理好一批单元后，将 JSON 数组写入文件：

```python
# 写入 JSON 文件供后续入库
import json

units = [...]  # 提取的单元列表

with open("extracted_units.json", "a", encoding="utf-8") as f:
    for unit in units:
        f.write(json.dumps(unit, ensure_ascii=False) + "\n")
```

每 50 个单元写一次文件，避免丢失。

## 素材来源优先级

| 优先级 | 来源 | 为什么 |
|--------|------|--------|
| ⭐⭐⭐ | 真实新闻事件 | 真实感最强，读者共鸣高 |
| ⭐⭐⭐ | 真实个人经历（知乎/豆瓣） | 情绪真实，细节丰富 |
| ⭐⭐ | 监控/纪录片片段描述 | 画面感强 |
| ⭐⭐ | 历史事件/传奇故事 | 天然有戏剧性 |
| ⭐ | 虚构短故事 | 可参考但价值较低 |
| ❌ | 纯 AI 生成的内容 | 不要提取 |

---

## 质量红线

- **不要水字数**：宁可 500 字写透，不要 1000 字注水
- **不要流水账**：要有情绪焦点，不要"然后...然后...然后..."
- **不要抄原文**：新闻/帖子必须改写，不能直接复制
- **不要 AI 味**：不要"不禁" "仿佛" "似乎" "内心涌起"
- **不要重复**：同一个故事不要提取多次
