## 1. 聊天气泡：QTextBrowser → QScrollArea + 自定义 Widget

### 背景
之前用 `QTextBrowser` + HTML 嵌套 table 渲染气泡，但 Qt 的 HTML 引擎不支持 `float`、`flexbox`、`max-width` 等 CSS 属性，气泡效果始终不对。

### 改动
- 新建 `ChatItemWidget` 类（`QWidget` + `QFrame` 气泡 + `QLabel` 文本）
- 替换 `_chat_view` 从 `QTextBrowser` 为 `QScrollArea` + `QVBoxLayout`
- 气泡样式：
  - **"我"**：绿色 `#95ec69`，圆角 `10px 4px 10px 10px`，靠右
  - **"写作助手"**：白色/暗色背景（主题自适应），圆角 `4px 10px 10px 10px`，靠左
  - **"系统"**：居中灰色文本
- 发送者标签独立一行在气泡上方（"我"/"写作助手"）
- 流式优化：新增 `_update_streaming()`，chunk 来临时原地更新最后一个气泡文本，不清除重建
- 新增 `_clear_layout()` 辅助方法递归清空布局
- 删除废弃的 `_build_bubble_html()` 方法

### 效果
每个气泡是真实 PySide 控件，样式完全可控。流式输出时不闪烁、不重建。

## 2. 对话自动草稿保存（关对话框不丢失）

### 背景
之前对话只在「创建项目」时才保存，关掉对话框后聊天记录丢失。

### 改动
- 新增 `_DRAFT_FILE` 常量 → `data/creation_conversation_draft.json`
- 重写 `closeEvent`：未创建项目时自动保存 `_conv_messages` + `_chat_messages`
- 新增 `_save_draft()`：写入 JSON 文件
- 新增 `_try_load_draft()`：打开对话框时自动恢复上次未保存的对话（文件读取后删除，防止重复恢复）
- 如果已创建项目（`_created_pid` 有值），不存草稿

### 效果
聊了几轮后关掉 → 自动存草稿 → 再打开自动恢复，可以继续聊。

## 3. 历史对话保存/读取修复

### 问题 1：`creation_conversation` 未注册到白名单
`setting_service.py` 的 `RECOGNISED_KEYS` 缺少 `"creation_conversation"`，导致 `set_setting`/`get_setting` 都抛 `ValidationError`，数据存不进去也读不出来。

**修复**：加入 `RECOGNISED_KEYS`。

### 问题 2：读取时数据结构对不上
`get_setting()` 返回 `{"project_id", "key", "data": {...}}`，但代码用 `conv_data.get("messages")` 直接取（应该在 `conv_data["data"]["messages"]`）。

**修复**：改为 `actual = conv_data.get("data")` → `msgs = actual.get("messages")`。

## 4. 历史面板三分区

### 背景
用户希望打开历史时左边显示历史列表、中间显示选中的历史对话（完整气泡）、右边保留当前聊天。

### 改动前
```
┌─────────────────────┬──────────────────────┐
│ 历史列表 + 底部小预览 │ 当前聊天              │
│ (QTextBrowser 120px) │                      │
└─────────────────────┴──────────────────────┘
```

### 改动后
```
┌─────────────┬───────────────┬─────────────────┐
│ 历史列表     │ 历史对话内容   │ 当前对话         │
│ (搜索+列表)  │ (完整气泡)     │ (输入/聊天)      │
│ 220-300px   │ 350-480px     │ 剩余空间         │
└─────────────┴───────────────┴─────────────────┘
```

- 左侧 `_history_list_panel`：搜索框 + 项目列表
- 中间 `_history_conversation_view`：`QScrollArea` + `ChatItemWidget` 气泡渲染历史对话
- 右侧：当前聊天区，不变
- 移除了底部的小尺寸 `_history_detail` QTextBrowser
- 对话框尺寸：780×680 → 1100×750
