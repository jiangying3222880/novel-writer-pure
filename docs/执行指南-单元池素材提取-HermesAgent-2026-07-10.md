# 单元池素材提取指南 — Hermes Agent 执行指令

大弟子 · 2026-07-10T20:19:00+08:00

---

## 你的任务

从网络收集短故事、新闻、贴吧帖子、小说片段，提取为符合格式的"故事单元"，存入单元池供小说创作使用。

**每个单元就像一个乐高积木**——情绪完整、独立可读、不超过 1000 字。写小说时直接从池里拼装使用。

---

## 输出格式（必须遵守）

每条单元输出一个 JSON 对象，多条放在一个数组里：

```json
[
  {
    "title": "标题（20字以内）",
    "content": "正文（1000字以内）",
    "genre": "题材分类",
    "scene_type": "场景类型",
    "emotion": "情绪基调",
    "tags": ["标签1", "标签2"]
  }
]
```

### 字段说明

| 字段 | 必填 | 说明 | 可选值 |
|------|:----:|------|--------|
| `title` | ✅ | 标题，20 字以内，概括核心 | 任意 |
| `content` | ✅ | 正文，**≤ 1000 字**，超长会被自动截断 | 任意 |
| `genre` | ✅ | 题材分类，尽量准确 | `通用` `仙侠` `都市` `悬疑` `言情` `科幻` `历史` `奇幻` |
| `scene_type` | ❌ | 场景类型，帮助后续检索 | `战斗` `感情` `揭示` `过渡` `高潮` `铺垫` `收束` |
| `emotion` | ❌ | 读完这个片段读者会有什么感觉 | `压抑` `爽` `虐` `燃` `甜` `愤怒` `悲伤` `恐惧` `温暖` `绝望` `希望` |
| `tags` | ❌ | 关键词标签，方便搜索 | 任意 |

## 什么是合格的故事单元

一个合格单元 = **情绪完整** + **有画面感** + **独立可读**

### ✅ 合格例子

```json
{
  "title": "废材觉醒",
  "content": "林轩睁开眼，发现自己正躺在柴房里。浑身酸痛，丹田空空如也。\n\n门外传来一阵嘲笑声，是二少爷的人在堵门。他没有动，只是静静听着外面的动静。上一世就是这样——冲动地冲出去，被打断双腿，逐出家门。\n\n这一世，他不会了。",
  "genre": "仙侠",
  "scene_type": "铺垫",
  "emotion": "压抑",
  "tags": ["觉醒", "废材流", "重生"]
}
```

**原因：** 有情绪（压抑→隐忍）、有画面（柴房/堵门）、独立可读。

### ❌ 不合格例子

```json
{
  "title": "林轩的冒险",
  "content": "林轩在柴房醒了过来，他发现自己被人堵在外面。然后他翻窗出去，遇到了二少爷的手下。打了一架之后他成功逃出。后来他去了青云宗拜师学艺。路上遇到一只妖兽，费了很大劲打死它。到了青云宗，守门弟子看不起他。",
  "genre": "仙侠",
  "scene_type": "其他",
  "emotion": "一般",
  "tags": ["仙侠"]
}
```

**原因：** 平铺直叙流水账，没有情绪焦点，没有画面感，像大纲不像故事。

## 不同来源的处理方法

### 一、短故事（完整故事 3000 字以内）

按情绪的"转折"拆成多个单元。一个情绪转折 = 一个单元。

```
一个短故事的结构可能这样拆：

开头（主角很惨，压抑）     → 单元 1
遇到贵人（出现希望）       → 单元 2
反转/高潮（爽/燃/虐）     → 单元 3
结局（温暖/余味）          → 单元 4
```

每段不超 1000 字，超长就从中间情绪最饱满的地方切一刀。

### 二、新闻 → 先改成文学语言

新闻是干巴巴的，要改成小说能用的样子。

```
新闻原文：
  "3月15日，某小区一老人摔倒，路人将其扶起送医。"

改写后：
  "小区的路灯还没全亮。张大爷只觉得脚下一软，膝盖磕在水泥地上，疼得眼泪都出来了。
  
  路过的外卖小哥停下电动车，犹豫了两秒——还是蹲下来，把老人扶了起来。
  
  老人的手冰凉，死死抓着小哥的胳膊，像抓着救命稻草。"
```

**规则：** 加五感（看到的/听到的/闻到的/触觉/温度），加心理活动，不要直接抄新闻词句。

### 三、贴吧/论坛故事 → 洗脏水，留金子

贴吧故事有真情绪，但需要清理：

**洗掉的：**
- "第一次发帖好紧张" "有人看吗" 等水话
- 网络梗（"我太难了" "蚌埠住了"）——这些写作用容易过时
- 语气填充词（"就是说""然后然后""就怎么说呢"）

**保留的：**
- 真实的愤怒、委屈、喜悦、愤怒——贴吧的情绪比编的强
- 生活细节——吵架的台词、奇怪的规矩、小人物的心理
- 对话节奏——真人对话比 AI 写的自然一千倍

### 四、长篇小说片段

从对话/场景中间截取一段，确保：
- 不依赖前面剧情也能看懂
- 有完整的小弧线（开始→发展→结束）
- 不是纯粹的旁白或说明

---

## 质量检查清单

每生成一个单元，自己检查一遍：

```
□ 字数 ≤ 1000？（超了要拆分或精炼）
□ 有明确的情绪？（读者会感觉到什么？）
□ 有画面感？（能看到场景吗？能听到声音吗？）
□ 独立可读？（不看到标题也能知道在讲什么）
□ genre 填了？（仙侠/都市/通用……至少选一个）
□ title 在 20 字以内？
```

---

## 批量提交方式

处理好一批单元后，JSON 文件直接交给项目，通过 `unit_pool_service.bulk_import()` 入库。

入库时内容超过 1000 字会自动截断并报警告，不影响其他单元的正常入库。
