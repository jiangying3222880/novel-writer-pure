## 实事 1: Character Arc 激活

### 新建 `app/services/character_arc_service.py`

**功能：**
- `get_arc_expectation(project_id, character_name, chapter_no)` — 从 book_outlines.character_arcs 查询角色在当前章节的预期弧线阶段
- `get_guides(unit_id, project_id)` — collect_guides() 接入点，为当前 unit 生成角色弧线 Guide
- `_heuristic_check(expected_stage, text)` — 启发式检测正文是否偏离预期弧线

**数据来源：** `book_outlines.character_arcs` (JSON 数组)

**Guide 输出示例：**
```
[character_arc 建议 | scope=Unit | confidence=0.70] 
角色【张无忌】当前应处于「犹豫」阶段，核心事件：学习九阳神功
```

### 修改 `app/core/types.py`

在 `collect_guides()` 函数中，`character_state` 之后注册 `character_arc_service`：

```python
# ---- character_arc (角色弧线) ----

        guides.extend(_arc.get_guides(unit_id, project_id=project_id))
except Exception:
    pass
```

## 实事 2: reverse_compile evidence_id 修复

### 修改 `app/services/reverse_compile.py`

**修改前：**
```python
def _calculate_weight_updates(patterns):
    updates = []
    for pattern in patterns:
        updates.append({
            "pattern_type": pattern["type"],
            "content_preview": pattern["content"][:50],
            "delta": pattern["weight_delta"],
            "evidence_id": None,  # 需要实际匹配
        })
    return updates
```

**修改后：**
```python
def _calculate_weight_updates(patterns):
    import hashlib
    updates = []
    for pattern in patterns:
        content = pattern.get("content", "")
        pattern_type = pattern.get("type", "")
        raw = f"{pattern_type}:{content[:100]}"
        evidence_id = f"rc_{hashlib.md5(raw.encode('utf-8')).hexdigest()[:12]}"
        updates.append({
            "pattern_type": pattern_type,
            "content_preview": content[:50],
            "delta": pattern["weight_delta"],
            "evidence_id": evidence_id,
        })
    return updates
```

**evidence_id 格式：** `rc_{md5hash12}` — 基于 pattern_type + content 前100字的 MD5，幂等可检索。

## 设计决策

- **不新建表** — 复用 book_outlines.character_arcs (Character Arc) 和 reverse_compile_results (模式提取)
- **不建 Evidence Library 系统** — Guide 系统已在消费现有数据
- **启发式优先** — Character Arc 偏离检测用关键词匹配, confidence=0.4 (软信号, 非硬判断)
- **幂等 evidence_id** — 同一 pattern_type+content 每次生成相同 ID
