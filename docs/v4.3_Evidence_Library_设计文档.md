## 2. 实事 1: Character Arc 激活

### 数据来源

`book_outlines.character_arcs` — JSON 数组，格式：

```json
[
  {
    "character": "张无忌",
    "stages": [
      {"chapter_range": [1, 10], "stage": "犹豫", "milestone": "学习九阳神功"},
      {"chapter_range": [11, 20], "stage": "成长", "milestone": "六大派围攻光明顶"}
    ]
  }
]
```

### 新建文件

`app/services/character_arc_service.py`

- `get_arc_expectation(project_id, character_name, chapter_no)` → 查询角色在当前章节的预期弧线阶段
- `get_guides(unit_id, project_id)` → collect_guides() 接入点，生成 Guide 对象
- `_heuristic_check(stage, text)` → 启发式检测正文是否偏离预期弧线

### Guide 集成

在 `app/core/types.py` 的 `collect_guides()` 中注册 `character_arc_service`。

## 3. 实事 2: reverse_compile evidence_id 修复

### 问题

`_calculate_weight_updates()` 返回 `evidence_id: None`（标记为 TODO），导致模式提取结果无法被 Guide 检索。

### 修复

基于 `pattern_type + content[:100]` 的 MD5 哈希生成确定性 ID：

```python
raw = f"{pattern_type}:{content[:100]}"
evidence_id = f"rc_{hashlib.md5(raw.encode('utf-8')).hexdigest()[:12]}"
```

幂等、可检索、不新建表。
